Privacy Policy

Effective date: 2026-11-21

"claude drive api" is a personal automation tool. Its owner runs it on their own computer to create and update Google Sheets in their own Google Drive.

What data the tool accesses

  • The tool uses one Google permission: drive.file.
  • It can access only Google Drive files that it created or that the user opened with it. It cannot see the user's other Drive files.
  • It reads the user's email address once, to confirm that the intended account was connected.

How the data is used

  • The data is used only to create, update and check spreadsheets that the owner asks for.
  • The owner may run the tool through an AI coding assistant on their computer. In that case, file contents the tool reads can be processed by that assistant, as directed by the owner.

Storage and sharing

  • The sign-in token is stored only on the owner's computer.
  • The tool has no server, analytics or advertising.
  • Data is not sold. It is not shared with anyone else.
  • This website sets no cookies.

Google API Services User Data Policy

Use and transfer of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

Access can be removed at any time at myaccount.google.com/permissions.
