claude drive api

A personal automation tool. Its owner uses it on their own computer to create and update Google Sheets in their own Google Drive.

  • It requests one Google permission: drive.file. With it, the tool can open only the files it created or files the user opened with it.
  • It is not a public service. There is no sign-up and no other users.
  • It runs only on the owner's computer. There is no server.
